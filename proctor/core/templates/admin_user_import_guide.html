👥 Bulk User Import Guide

Learn how to import multiple users at once

📥 Download User Template

Start by downloading our pre-formatted template

Download UsersTemplate.xlsx
1 Prepare Your User Data

The template has the following structure:

Template Format

username email password role first_name last_name
john_doe john@example.com Pass@1234 Student John Doe
jane_smith jane@example.com Secure@5678 Faculty Jane Smith

Important Rules

• Do NOT change column headers
• Required fields: username, email, password, role
• Optional fields: first_name, last_name
• Role must be: Student, Faculty, or Admin (case-sensitive)
• Each username and email must be unique
• Use strong passwords (minimum 8 characters recommended)

2 Fill in User Information

For each user you want to add:

  • username: A unique identifier for login (alphanumeric, underscores allowed)
  • email: A valid email address
  • password: The initial password for the user
  • role: Must be exactly Student, Faculty, or Admin
  • first_name: User's first name (optional but recommended)
  • last_name: User's last name (optional but recommended)

Pro Tip

You can import hundreds of users at once! Just add more rows to the template. The system will validate each entry and skip duplicates automatically.

3 Save as CSV or Excel

Once you've filled in all user data:

  • Save the file as CSV (.csv) or keep it as Excel (.xlsx, .xls)
  • Both formats are supported by the system
  • Make sure there are no empty rows between user entries

CSV vs Excel

CSV: Simple text format, works everywhere
Excel: Keeps formatting, easier to edit
Both work perfectly with our import system!

4 Upload to System

Go to the User Management page and:

  1. Click the "Import from File" button
  2. In the modal, click "Choose File"
  3. Select your prepared CSV or Excel file
  4. Click "Import Users"

What Happens Next?

The system will:
• Validate all user data
• Check for duplicates
• Create all valid users
• Show you a summary of imported users
• Report any errors or skipped entries

5 Verify Imported Users

After import:

  • Check the success message for import statistics
  • Use the search function to verify users were created
  • Filter by role to see all newly imported users
  • Users can now log in with their imported credentials

Troubleshooting

If the import fails:
• Check that column headers match exactly (case-sensitive)
• Ensure role values are exactly: Student, Faculty, or Admin
• Verify all usernames and emails are unique
• Make sure there are no special characters in usernames
• Check that email addresses are valid

Common Errors:
• "Duplicate username" - That username already exists in the system
• "Invalid role" - Role must be Student, Faculty, or Admin (exact case)
• "Missing required field" - username, email, password, or role is empty
• "Invalid email format" - Email address is not properly formatted

Bulk Operations

Best Practices:
• Test with a small file first (5-10 users) to ensure format is correct
• Keep a backup of your import file
• Generate strong, unique passwords for each user
• Inform users of their credentials securely after import
• Consider sending password reset links for users to set their own passwords
